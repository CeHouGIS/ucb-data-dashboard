# UCB Data Dashboard

按项目与数据阶段组织的目录登记册。20个项目入口、3个共享/待归属入口、3个辅助工具入口。

项目内部分类为原始数据、中间数据、成果数据、模型权重、参考数据、缓存与临时数据、元数据与清单、混合目录/待确认。分类来自目录名称及部分项目说明，不代表逐文件核验。

原始265条目录记录全部保留；同一项目下同相对路径的多个存储位置集中显示，不代表已去重。实际文件未移动、合并或删除，待Savio传输完成后再核对。

备注保存在浏览器，可导入导出；旧版位置备注仍可读取。公开索引隐藏服务器绝对路径。
